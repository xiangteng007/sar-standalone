# SAR Standalone｜協尋覆蓋協作演練平台

可自行建置與部署的 Node.js／SQLite／React 專案。支援山林搜尋覆蓋、人員搜尋覆蓋與動物協尋的合成演練；點、線、面標註、JPEG/PNG 照片、位置核對、審核、GeoJSON 匯出及結案。

**目前是 v0.5 演練原型，尚未完成真實 Google 登入、HTTPS 部署與完整實機驗收。公開的是程式碼，不是可公開使用的救援服務。** 沒有預設帳號或繞過登入的入口。不同核准帳號的資料分開；尚非多人共同管理同一案件的成熟平台。

## 從原始碼建置

需要 Node.js 24.22.1 或更新的相容版本及 npm。

```sh
npm ci
npm run check:public
npm run build
npm test
```

建置產物為 `outputs/standalone/`，可複製至私人部署機，無須原始碼或 ChatGPT Sites。

```sh
cd outputs/standalone
npm ci --omit=dev
# 複製 .env.example 為 .env，於私人環境自行填寫已核准設定。
node --env-file=.env server.mjs --check-config
node --env-file=.env server.mjs
```

設定範例不能直接登入。必須配置真正 Google Web OAuth client、完全一致的 origin，以及事先驗證核准的 Google `sub` 白名單；不能用 email 代替 sub，不會自動接納第一個登入者。請勿在 Issues、程式或提交中放入帳號設定、權杖或真實個案資訊。部署詳見 [操作說明](standalone/README.md)。

服務綁定 loopback；遠端使用須由管理者配置受控 HTTPS 反向代理，保留設定的 Host。原始碼公開不會自動開放服務、防火牆或資料。停止服務可在其終端按 Ctrl+C；不要終止其他服務。

## 隱私與限制

- 倉庫沒有案件資料、真實照片、資料庫、備份、登入設定或私人站台資訊。測例只建立臨時合成資料；簽章測例在執行時產生暫時 RSA 金鑰，沒有內嵌私人金鑰。
- 原照片不會移除 EXIF，也未提供影像去識別化、HEIC、GPX、永久離線草稿或背景追蹤。現階段只使用合成資料。
- SQLite 與照片需由主機權限、加密及備份政策保護；程式不宣稱具備資料靜態加密。
- 僅核准且符合類型的搜尋成果會匯出；「曾搜尋」不代表已排除。結案停止新增、審核與匯出，資料不自動刪除。
- 地圖與 Google 登入需連網。底圖請求會向第三方提供所瀏覽圖幅。預設地圖為臺灣概覽；測試座標是合成範例。
- 人員線索請交正式窗口，不可用於追蹤私人行蹤。本平台不是報案、導航安全認證、醫療或派遣服務，不能取代緊急求助。

## 驗證

`npm test` 執行八組測試：HTTP、乾淨安裝／程序啟停、Google 簽章合成驗證、備份還原、部署設定、儲存故障、定位／傳輸與登入回應。報告寫入被 Git 排除的 `verification/`。Google claims／裝置定位仍是合成；本機通過不代表真人登入或實機驗收通過。

`npm run check:public` 檢查已追蹤檔案的公開內容邊界與常見秘密形式；屬輔助檢查，不能保證偵測所有秘密。公開前另需人工檢查程式、附件與提交中繼資料。禁止將原私人倉庫的 Git 歷史合併至此。
